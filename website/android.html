First-time installation

One source. A few clear steps.

These steps start inside Kodi. If Kodi is not installed yet, get it from the official Kodi download page ↗.

One source address. Both platforms.

Add this in Kodi File manager and name it CBR.

The website explains the setup. The source address above is the one to enter in Kodi.

  1. Add CBR as a file source

    Open Kodi’s settings and follow:

    File manager → Add source → <None>

    Enter the source address above exactly, including https://. Name the source CBR and select OK.

  2. Install the Android / Fire TV repository

    Add-ons → Install from zip file → CBR → repository.cbr.zip

    If Kodi asks you to enable Unknown sources, use Settings → System → Add-ons → Unknown sources, then return to this step.

  3. Install Crimson Blood Requiem

    Install from repository → CBR Android Add-on Repository → Video add-ons → Crimson Blood Requiem → Install

    Accept the dependency list, including CBR Playback Engine. Kodi installs it automatically. There is no separate companion APK to install.

  4. Restart Kodi, then open CBR

    Fully close and reopen Kodi to load the background services. Open Add-ons → Video add-ons → Crimson Blood Requiem, using the crimson CBR thumbnail.

    Choose your movie, series or live TV section. Provider links and schedules depend on the sources configured on this device.

Already installed?

Update without starting over.

Use the video add-on’s Information → Update option. If Kodi’s repository list has not refreshed, install the latest platform ZIP directly:

Install from zip file → CBR → cbr092.zip

Restart Kodi afterwards. You do not need to uninstall CBR or reinstall the skin for a video add-on update.
