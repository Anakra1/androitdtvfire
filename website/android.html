First-time installation

One source. A few clear steps.

These steps start inside Kodi. If Kodi is not installed yet, get it from the official Kodi download page ↗.

One source address. Both platforms.

Add this in Kodi File manager and name it CBR.

The website explains the setup. The source address above is the one to enter in Kodi.

  1. Add the CBR source in Kodi

    Settings (cog) → File manager → Add source → <None>

    Enter https://anakra1.github.io/androitdtvfire/ exactly. Name it CBR, select OK, then return to Kodi’s home screen. Use this source address, not the website’s /website/ address.

  2. Allow installation from ZIP

    Settings → System → Add-ons → Unknown sources

    Enable this option and accept Kodi’s warning if you want to install CBR. Return to Add-ons → Install from zip file.

  3. Install the full Android / Fire TV package

    Add-ons → Install from zip file → CBR → fulla046.zip

    This is Setup Wizard 0.4.6, containing CBR 0.12.3, the crimson skin, playback engine, update repository and Kodi 21 ARM TV components. Wait for the CBR Setup Wizard installed / updated notification. A separate repository install is not needed first.

    Download fulla046.zip

  4. Run the wizard — installing the ZIP is only the first step

    Add-ons → Program add-ons → CBR Setup Wizard

    Open the wizard. If Kodi shows its information page with Run, Configure and Uninstall, choose Run.

    Select Full install / repair. Let it finish installing or configuring the components, generating channels and downloading programme information. It also applies the CBR skin. Wait for the completion message.

  5. Close and reopen Kodi

    Use Kodi’s power menu and choose Exit, then open Kodi again. On Fire TV, pressing Home alone leaves Kodi running.

    The crimson CBR home screen should now appear. Open CBR Movies, CBR TV Series or Kodi’s TV → Guide. Guide loading can take a little time on the first run.

  6. Configure sports streaming when needed

    Movies and series use the starter Cinemeta and Torrentio sources; playback depends on available streams. Sports Streams needs your own current configured manifest.

    Open CBR → Source setup (phone / PC). Keep the setup screen open and enter its exact http:// address in a browser on the same home network. Paste your manifest into the Sports Streams provider and save. See phone / PC source setup.

Still seeing Kodi’s default blue skin? Open CBR Setup Wizard → Run → Apply CBR space interface only and confirm. If the skin is missing, run Full install / repair first. You can also select Settings → Interface → Skin → Skin → Crimson Blood Requiem once it is installed.

Already installed?

Update without starting over.

New in CBR 0.12.7: open CBR Setup for separate Live TV, Movies, TV Series, Channel Listings, Programmes and Tools categories. The paired phone / PC page uses the same categories.

Automatic updates from CBR 0.12.2: CBR asks Kodi to check repositories about 30 seconds after startup, when nothing is playing. Kodi installs available updates when Settings → System → Add-ons → Updates → Install updates automatically and the component’s Auto-update switch are enabled.

One-time setup for a ZIP / full-installer installation: open Add-ons → My add-ons → Video add-ons → Crimson Blood Requiem → Information → Versions (or Update), then select the version supplied by the CBR Android Add-on Repository. Allow Kodi to install it, even if the version number is the same. This links CBR to its repository. Repeat for the CBR skin under Look and feel → Skin and Setup Wizard under Program add-ons if you want them updated automatically too. Keep the repository installed and enabled.

No source URLs or personal manifests are replaced by this check. Provider verification links may still need renewing. You can turn the startup check off in CBR → Configure → Updates.

For an installation linked to the CBR repository, use the video add-on’s Information → Update option. For a direct ZIP installation, or if the update is not offered, use the platform ZIP below:

Install from zip file → CBR → cbr0127.zip

Restart Kodi afterwards. cbr0127.zip updates only the video add-on. For a first install, a missing skin or a full repair, use fulla046.zip and run the wizard instead. You do not need to uninstall CBR for either update.

Check, repair and move your setup.

In CBR, open Sources and player settings → Check, repair and back up CBR. The same tools are available from CBR Setup Wizard → Check and repair CBR.

Use Check and repair CBR to request refreshed defaults and TV guide setup while Kodi is idle. Use Test sources to distinguish available catalogues, responding stream samples and providers needing a renewed manifest. A sample response is not a guarantee of continuous playback or English audio.

Open the paired phone / PC page for a diagnostic report, channel favourites, groups and backup / restore. Personal backups can include private manifest URLs; keep those files private. Channel-layout-only backups omit personal sources and saved channels.

Removing CBR

Uninstall on Android / Fire TV.

Wizard 0.4.6 offers CBR-only removal. First switch to Settings → Interface → Skin → Skin → Estuary and confirm Keep skin. Stop playback, then open CBR Setup Wizard → Uninstall CBR. It checks for other addons depending on CBR and asks what to remove. Choose Keep settings to preserve your manifests and favourites, or explicitly choose Remove settings for a fresh start. Restart Kodi afterwards. Official IPTV/inputstream clients and unrelated TV configurations are kept.

If the wizard cannot open, use the manual steps below.

This removes CBR while keeping Kodi and your other add-ons. Stop any playing video first. Skip any component you have not installed.

“This add-on is required by CBR”? Remove the CBR Setup Wizard first, then the CBR skin, then the video add-on. Disabling a dependent add-on alone does not remove its dependency.

  1. Restore your previous skin first

    While the wizard is still installed, open CBR Setup Wizard → Restore previous Kodi interface and confirm.

    If the wizard cannot open, choose Settings → Interface → Skin → Skin → Estuary and confirm the change. Continue once a different skin is active.

  2. Disconnect CBR’s TV guide, if configured

    Add-ons → My add-ons → PVR clients → PVR IPTV Simple Client → Configure

    Choose Remove add-on configuration and select CBR TV. If CBR TV is the only configuration, Kodi may not offer removal: open that configuration and disable it instead.

    Keep other TV configurations. Leave IPTV Simple Client installed if you use it for other channels.

  3. Remove the wizard, skin and video add-on in order

    Open each add-on’s information screen and choose Uninstall:

    1. Add-ons → My add-ons → Program add-ons → CBR Setup Wizard → Uninstall2. Add-ons → My add-ons → Look and feel → Skin → Crimson Blood Requiem → Uninstall3. Add-ons → My add-ons → Video add-ons → Crimson Blood Requiem → Uninstall

    If Kodi still blocks removal, it will name the add-on that depends on it. Remove that CBR component first, then retry.

  4. Remove the unused Android playback engine

    After removing the CBR video add-on, remove CBR Playback Engine only if Kodi shows that no other add-on needs it.

    Settings → System → Add-ons → Manage dependencies → CBR Playback Engine → Uninstall

    If Manage dependencies is hidden, change the settings level to Advanced or Expert. If Kodi still names another dependent add-on, keep the engine until that add-on has been removed.

  5. Remove the repository and file source, if wanted

    Add-ons → My add-ons → Add-on repository → CBR Android Add-on Repository → Uninstall

    To remove the saved download source, open Settings → File manager. Highlight the CBR source and long-press Select / OK on the remote to open its context menu. Choose Remove source. This removes the CBR bookmark, not the online repository or anyone else’s installation.

  6. Choose what to keep, then restart Kodi

    If Kodi asks whether to remove related add-on data, keep it to retain settings for a reinstall, or remove it for a fresh start. Removing data can erase that component’s saved manifest URLs, favourites and channel customisations.

    Fully close and reopen Kodi to stop the old services and refresh its TV listings.

    If you installed the old, separate CBR companion app in the past, it is a separate optional cleanup. On Fire TV use Settings → Applications → Manage Installed Applications → the CBR companion app → Uninstall. On Android TV use the device’s Settings → Apps. Current CBR installations do not install this app.

Do not use Clear data for the Kodi app, uninstall Kodi itself, or delete its whole userdata folder just to remove CBR: those actions also affect your other Kodi settings and add-ons.
