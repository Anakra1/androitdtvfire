Pluto TV UK

Add Pluto UK channels to CBR.

Browse all Pluto UK channels Download channel list

This maintained third-party M3U lists Pluto TV UK channels. Keep the exact URL below: current CBR versions recognise it and request a fresh Pluto playback session when you select a channel.

Open Pluto TV UK playlist

  1. Connect your PC or phone to CBR. In Kodi open CBR Setup → Connect phone or PC / edit manifest links, then follow the pairing steps. Keep the setup screen open on the TV.
  2. On the paired page, select Live TV. If Pluto TV UK is already listed, select Edit; otherwise choose Add a Live TV source.
  3. Set Source name to Pluto TV UK and paste the complete playlist address into Manifest or M3U playlist URL.
  4. Choose Live TV category → Internet TV. Set Programme country → United Kingdom, keep Enabled in CBR checked, then select Add source or Save changes.
  5. Return to Kodi and reopen CBR → Live TV → Internet TV to browse the Pluto UK source.

Also include Pluto in Kodi’s TV guide.

On the paired page, stay in Live TV, find Choose sources for the Kodi TV guide, tick the Pluto UK catalogue and select Save TV sources, then Build / refresh TV. Use Channel Listings to choose channel groups, names, numbers and favourites. If Kodi TV has not been configured before, follow the first-time TV setup steps.

Use the playlist URL, not the Pluto website address. The pluto.tv/gb_ie/watch/live-tv/ page is for browser viewing. Do not copy individual session-bearing stream addresses out of the playlist. Channel availability depends on your location and Pluto’s current lineup.

The playlist is maintained by BuddyChewChew/pluto; it is not an official Pluto export. Valid stream manifests do not by themselves confirm sustained playback.

How to add this live TV source

Add or update any live TV playlist.

  1. Pair your PC or phone with Kodi and open the Live TV tab.
  2. Edit the existing source, or choose Add a Live TV source if it is new. Copy its playlist URL above and paste it into Manifest or M3U playlist URL.
  3. Give it a recognisable name. Use the category shown on its card: TV Channels or Internet TV. Leave Programme country on Automatic for mixed-country lists; choose United Kingdom for UK-only sources.
  4. Keep the source enabled and save. Return to CBR and reopen the source’s live channel catalogue.
  5. For Kodi’s main TV guide, select the source’s catalogue under Choose sources for the Kodi TV guide, save TV sources, then build / refresh TV. Use Channel Listings to choose groups, channel numbers, names and favourites.

Use the URL ending in the actual playlist filename, not the project’s GitHub webpage. Add only the catalogues and countries you need.

Step 2 · Renew a personal provider link

Update Sports Streams.

Open Sports Streams settings

  1. Open the settings page above on your phone or PC. Complete its human-verification step yourself if requested.
  2. Choose sports and leagues. If you want its live channel catalogue, check the Catalogs → 24/7 channels options. Save your settings where offered.
  3. Go to the provider’s Install section and choose Copy link, sometimes labelled Copy Manifest URL. Copy the complete generated addon link. You do not need to install Stremio to copy a link for CBR.
  4. Return to the paired CBR tab. Select Live TV, then under your sources, find Sports Streams and press Edit. Replace Manifest or M3U playlist URL with the copied link.
  5. Choose Live TV category → Live Sports, leave Enabled in CBR checked and press Save changes. Leave Programme country on Automatic for mixed-country sports.
  6. Press Refresh catalogues. Reopen the sports category in CBR Live TV or use Refresh listings. If those channels are also used in Kodi’s main TV guide, follow the TV refresh steps below.

Use the full configured link, not just the ID. The generated URL carries your configuration/ID. The bare https://sports.highfly.dev/manifest.json is a public default and may return renewal notices instead of your configured streams. A /configure webpage is not a manifest.

CBR accepts complete https:// and stremio:// addon links. Keep personal IDs and configured URLs private. Sports Streams and StreamsPPV are separate providers: edit the entry belonging to the link you generated.

Movie and episode sources

Movies & TV series.

These are Stremio-style provider links rather than live-TV playlists. Add them in Movies or TV Series on the paired setup page. A shared provider appears in both categories using one saved configuration.

Cinemeta — film and series catalogue

Provides titles, posters, descriptions, seasons and episode information. It does not supply video playback streams.

Choose Add a Movies source or Add a TV Series source, name it Cinemeta, paste the link, leave it enabled and save. You can also add Cinemeta directly from the corresponding source folder in Kodi.

Torrentio — movie and episode source results

Use its configuration page to choose providers and options. Copy your complete generated manifest link; do not enter the configuration-page address as the manifest.

Open Torrentio configuration
  1. Choose and save your settings on the provider page.
  2. Copy the complete configured addon link.
  3. On the paired CBR page, open Movies or TV Series and edit Torrentio, or add it if absent.
  4. Paste the link, keep the source enabled and save. Reopen the film or episode to refresh its available links.

Configured links can contain account credentials. Keep them private. Source results do not guarantee playback or permission to access an item. Movie and series sources are not added to the PVR channel guide.

Update your existing installation

In Kodi, open Add-ons → My add-ons → Video add-ons → Crimson Blood Requiem → Information → Update / Versions and choose the release from the CBR repository. Kodi can install updates automatically when the add-on is repository-linked and automatic updates are enabled. For a manual update, install the platform update ZIP above and restart Kodi. Existing source settings are retained.
