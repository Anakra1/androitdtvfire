First-time installation

One source. A few clear steps.

These steps start inside Kodi. If Kodi is not installed yet, get it from the official Kodi download page ↗.

One source address. Both platforms.

Add this in Kodi File manager and name it CBR.

The website explains the setup. The source address above is the one to enter in Kodi.

  1. Add CBR as a file source

    Open Kodi’s settings and follow:

    File manager → Add source → <None>

    Enter the source address above exactly, including https://. Name the source CBR and select OK.

  2. Install the Windows repository

    Add-ons → Install from zip file → CBR → windowsrepo.zip

    If Kodi asks you to enable Unknown sources, use Settings → System → Add-ons → Unknown sources, then return to this step.

  3. Install Crimson Blood Requiem

    Install from repository → CBR Windows Add-on Repository → Video add-ons → Crimson Blood Requiem → Install

    The Windows playback engine is already bundled. The Windows package does not require the Android CBR Playback Engine module.

  4. Restart Kodi, then open CBR

    Fully close and reopen Kodi to load the background services. Open Add-ons → Video add-ons → Crimson Blood Requiem, using the crimson CBR thumbnail.

    Choose your movie, series or live TV section. Provider links and schedules depend on the sources configured on this device.

Removing CBR

Uninstall on Windows.

This removes CBR while keeping Kodi and your other add-ons. Stop any playing video first. Skip any component you have not installed.

“This add-on is required by CBR”? Remove the CBR Setup Wizard first, then the CBR skin, then the video add-on. Disabling a dependent add-on alone does not remove its dependency.

  1. Restore your previous skin first

    While the wizard is still installed, open CBR Setup Wizard → Restore previous Kodi interface and confirm.

    If the wizard cannot open, choose Settings → Interface → Skin → Skin → Estuary and confirm the change. Continue once a different skin is active.

  2. Disconnect CBR’s TV guide, if configured

    Add-ons → My add-ons → PVR clients → PVR IPTV Simple Client → Configure

    Choose Remove add-on configuration and select CBR TV. If CBR TV is the only configuration, Kodi may not offer removal: open that configuration and disable it instead.

    Keep other TV configurations. Leave IPTV Simple Client installed if you use it for other channels.

  3. Remove the wizard, skin and video add-on in order

    Open each add-on’s information screen and choose Uninstall:

    1. Add-ons → My add-ons → Program add-ons → CBR Setup Wizard → Uninstall2. Add-ons → My add-ons → Look and feel → Skin → Crimson Blood Requiem → Uninstall3. Add-ons → My add-ons → Video add-ons → Crimson Blood Requiem → Uninstall

    If Kodi still blocks removal, it will name the add-on that depends on it. Remove that CBR component first, then retry.

  4. Windows playback-engine cleanup

    The Windows engine is bundled inside the video add-on and is removed with it. There is no separate Windows engine application to uninstall.

    If an older installation left CBR Playback Engine behind, you can remove that unused module through Settings → System → Add-ons → Manage dependencies, provided Kodi says nothing else needs it.

  5. Remove the repository and file source, if wanted

    Add-ons → My add-ons → Add-on repository → CBR Windows Add-on Repository → Uninstall

    To remove the saved download source, open Settings → File manager. Right-click the CBR source, or highlight it and press C, to open its context menu. Choose Remove source. This removes the CBR bookmark, not the online repository or anyone else’s installation.

  6. Choose what to keep, then restart Kodi

    If Kodi asks whether to remove related add-on data, keep it to retain settings for a reinstall, or remove it for a fresh start. Removing data can erase that component’s saved manifest URLs, favourites and channel customisations.

    Fully close and reopen Kodi to stop the old services and refresh its TV listings.

Do not use Clear data for the Kodi app, uninstall Kodi itself, or delete its whole userdata folder just to remove CBR: those actions also affect your other Kodi settings and add-ons.
