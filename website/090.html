Earlier version

CBR 0.9.0 clean install.

The original playback code and sources, with separate Windows and Android packaging. The previously used TVVoo configuration is included. No DaddyLive, IPTV-org import or later link caching.

Windows repository · w090repo.zipAndroid / Fire TV repository · a090repo.zip

Prepare a clean baseline.

  1. Save any personal manifest links you need, then switch to the Estuary skin.
  2. Disable/remove the old CBR TV instance in IPTV Simple, leaving other providers alone.
  3. Uninstall the CBR wizard, skin and video addon in that order. Choose to remove CBR data for a fresh setup; this removes CBR favourites, manifests and channel customisations.
  4. Disable/uninstall the normal newer CBR repositories, then restart Kodi.
  5. From your existing CBR source, install w090repo.zip on Windows or a090repo.zip on Android/Fire TV.
  6. Install Crimson Blood Requiem from the matching CBR 0.9.0 repository. Verify Information shows 0.9.0. Disable Auto-update if newer CBR repositories remain enabled.
  7. Restart Kodi. Open CBR → Live TV → Kodi TV and guide → Set up Kodi TV / IPTV Simple Client.

The skin and wizard are optional and available from the same repository. Android playback stays inside Kodi through its existing engine dependency.

Restoring an older addon cannot restore upstream streams that have stopped working.
