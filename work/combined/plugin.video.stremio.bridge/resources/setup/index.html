Your sources

Add a source

For mixed-country sources, leave Automatic selected. Choose a country only when the source contains channels from that country.

Programme information

Schedules are separate from streaming manifests. The UK feed is included automatically; other countries need a matching XMLTV feed. Programme times use the TV’s time zone.

Add a programme feed

After saving, return to CBR’s home menu and reopen the catalogue. Changes are stored on your Kodi device.
