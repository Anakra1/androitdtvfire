# Local sport-first CBR prototype

Applied to the Windows 0.9.0.1 trial on 15 November 2026. The Android 0.10.4/full installer 0.2.3 work rebases these patches onto the released Android source; 0.10.3/fulla022.zip remains the previous release.

CBR → Live TV → Live Sports now opens sport categories (Football, motor sports, cricket, rugby, tennis, golf and others). Each category lists provider events and a separate sports-channel folder, since mixed-sport networks do not guarantee that they are currently showing the selected sport. Sports Streams event catalogues and live channels are combined with the existing Samsung/DuckKota UK channel sources. Exact same-name channels merge only for a known matching country; source IDs remain intact for fresh resolution. Unknown countries and separate event providers are kept distinct. Provider stream options are interleaved so one source cannot consume every fallback slot. Disabled sources are excluded. Metadata is cached; playback URLs are resolved on selection. Favourites and recent entries retain the variant list.

The Crew integration opens its installed, enabled Kodi add-on's matching sport menu (Football/fifa, F1, tennis, NBA, NFL and others). It does not copy every Crew resolver or merge Crew's internal links into CBR's automatic fallback list. Its current menu routes were checked against official Crew 3.2.2/module 3.2.29. Windows has no Crew installation, so this handoff has fixture coverage but no native Crew playback test. The user confirmed Crew is installed on Fire TV.

DaddyLive's catalogue returned 879 channels, including 56 classified as UK by the existing adapter. Direct playback tests for Sky Atlantic and Sky Sports Main Event failed. Further provider/player checks also failed. Current player pages contain a browser-verification flow and do not expose the TICKET expected by the reviewed standalone 5.2.7/Crew resolver. No browser challenge was automated or bypassed. The new DaddyLive source is retained disabled and excluded from PVR. Enabling it manually does not mean its streams will work.

`prototype/` and `prepare_proxy.py` contain an isolated, unsuccessful transport experiment using reviewed GPL Crew proxy logic and MIT pyaes. They are not installed in Kodi or included in a release. Do not package them as verified playback support. Upstream downloaded code was inspected as text; remote Python from Crew XML feeds was not executed in CBR.

Checks passed: Python 3.8 syntax; sport classification including NFL vs football; generic-channel separation; country-safe merging; provider diversity; disabled-source handling; bookmarks; PVR isolation; conditional Crew handoff. Real Windows Kodi returned the new sport menus, 22 Football event entries and 41 channel entries at inspection (provider listings change). Sky Sports Main Event and Tenerife vs Ceuta produced video and audio; football video was visually confirmed. The selected football feed was a Spanish broadcast; English commentary was not established. Kodi's PVR configuration hash and guide groups remain unchanged. The existing updater added three current sporting events to the exported playlist during the restart; no prior channels were removed. DaddyLive is excluded from that export.

Reviewed source files are under `overlay/`. Original code/profile backups and private configured source details are under ignored `outputs/verified-live-daddy-menu-20261115/`. Never publish those backups or signed stream URLs. Rebase patches onto the Android release tree before building a future package; the Windows entry point is an older local baseline.
